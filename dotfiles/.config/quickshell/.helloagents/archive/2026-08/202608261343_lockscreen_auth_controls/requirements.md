# 锁屏认证与操作控件重构 — 需求

确认后冻结，执行阶段不可修改。如需变更必须回到设计阶段重新确认。

## 核心目标
让本机用户在锁屏出现后立即看懂认证入口，并消除字体字形边界导致的右上角图标视觉偏心。

## 功能边界
- 认证区改为横向身份行、圆角凭据框、右侧内嵌解锁按钮与固定高度状态槽。
- 空密码即使输入框已聚焦也显示“输入密码”；PAM 活跃时禁用输入与提交并显示加载反馈。
- 认证失败仅水平抖动完整凭据框，且不改变认证区整体高度。
- 电源与 idle 图标改为 `Canvas` 固定坐标矢量，并合并到统一操作胶囊。
- 电源菜单移除混用的 Unicode 图标，只保留中文动作文字。
- 新增隔离布局测试并改写既有电源控件测试，不启动锁屏、不执行 PAM、idle 或电源命令。

## 非目标
- 不修改 PAM 会话、认证结果、idle-control 或 systemctl 的业务链路。
- 不重做壁纸、时钟、粒子或底部“已锁定”状态栏。
- 不引入第三方图标库、字体依赖或位图资源。

## 技术约束
- 使用 Qt Quick / Quickshell 现有技术栈和 `Config.Theme` 动效 token。
- `LockGlyph` 必须完全独立于字体 fallback，并由确定性 Canvas 坐标绘制。
- `PowerControls` 与认证组件只发信号或维护局部表现状态，系统副作用继续由 `lockscreen/shell.qml` 持有。
- 保留 `QUICKSHELL_REDUCE_MOTION` 行为与现有动态配色输入。

## 质量要求
- 新增组件全部通过 `qmllint -I /usr/lib/qt6/qml`。
- 两个隔离 `*-check.qml` 覆盖几何、焦点占位、PAM busy、错误高度稳定与无构造副作用。
- 完成 offscreen 运行验证、源码残留扫描、`git diff --check` 和变更范围审计。
